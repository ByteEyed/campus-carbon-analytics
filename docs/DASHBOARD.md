## 1. Overview & Architectural Role

Phase 17 implements the **Executive Dashboard**, an interactive web-based presentation layer built with **Streamlit** and **Plotly**. 

The dashboard adheres strictly to the **Read-Only Separation of Concerns** architectural principle:
- **Presentation-Only Role:** The dashboard consumes precomputed, audited static artifacts generated by the Phase 16 Integrated Pipeline in [`data/processed/pipeline_run/`](file:///d:/user%20(sarthak)/projects/campus-carbon-analytics/data/processed/pipeline_run).
- **Zero Recalculation:** It executes zero mathematical calculations, carbon accounting, model fitting, Monte Carlo simulations, or combinatorial optimizations.
- **Data Integrity:** It never converts missing values into zeros merely to display a complete chart.
- **Clean Ingestion:** All filesystem I/O is encapsulated inside [`src/dashboard/adapter.py`](file:///d:/user%20(sarthak)/projects/campus-carbon-analytics/src/dashboard/adapter.py), utilizing Streamlit's in-memory data cache (`@st.cache_data`).

## 3. How to Launch the Dashboard

### 3.1 Prerequisite: Ensure Phase 16 Artifacts Exist
The dashboard expects precomputed artifacts in `data/processed/pipeline_run/`. If not yet generated, run:
```bash
# Execute Phase 16 integrated pipeline
python -m src.pipeline --simulations 50
```

### 3.2 Launching the Streamlit Application
```bash
# Run local executive dashboard
streamlit run src/dashboard/app.py
```
By default, the server will open in your web browser at:
`http://localhost:8501`

### 3.3 Running Headless / Custom Port
```bash
streamlit run src/dashboard/app.py --server.port 8501 --server.headless true
```

## 4. Page-by-Page Feature Tour

The dashboard uses a sidebar-driven Single-Page App (SPA) layout containing five distinct views:

### 4.1 🏛️ Executive Overview
- **Top Metric Cards:**
  - **Total Historical Emissions:** Cumulative campus footprint ($4,196.19\text{ MTCO}_2\text{e}$ across 2023–2025).
  - **Emissions Intensity:** Per student-month intensity ($25.48\text{ kgCO}_2\text{e/student-month}$).
  - **Optimal Decarbonization Abatement:** Avoided carbon ($225.8\text{ MTCO}_2\text{e/yr}$ / $15.80\%$ reduction relative to 2025 baseline).
  - **Capital Outlay & Surplus:** Required capital (₹9.50 Lakhs) against the ₹25 Lakh budget cap, highlighting ₹15.50 Lakhs in conserved capital.
- **Visuals:**
  - **48-Month Transition Horizon:** Historical observed emissions (months 1–36) connected cleanly to 12-month forward projections (months 37–48).
  - **Category Donut Chart:** Breakdown illustrating that grid electricity represents **79.77%** of campus emissions.
- **Executive Takeaways Box:** Synthesizes dominant Scope 2 drivers, optimization findings, and model robustness.

### 4.2 📊 Historical Accounting
- **Monthly Stacked Bar Chart:** 36-month timeline showing Electricity, Travel, Waste, and Procurement stacked monthly.
- **Facility Cumulative Bar Chart:** Total emissions per campus building archetype (Hostel & Dining, Science Complex, Library, Arts, Admin).
- **Facility Intensity Table:** Mean student headcount and per-student emissions intensity per facility.
- **Top 10 Emissions Drivers Table:** Audited list of the highest-emitting building-months in the dataset.

### 4.3 📈 Forecasting & Uncertainty
- **Interactive Target Selector:** Filter between Total Campus Emissions, Electricity Emissions, and Travel Emissions.
- **Model Performance Metrics Cards:** Displays empirical Phase 11 hold-out validation metrics from `primary_model_evaluation_summary.csv`:
  - Mean Absolute Error (MAE): $1,548.20\text{ kgCO}_2\text{e}$
  - Root Mean Squared Error (RMSE): $1,975.93\text{ kgCO}_2\text{e}$
  - Mean Absolute Percentage Error (MAPE): **1.27%** (significantly beating the Naive baseline's 39.50%)
  - Prediction Interval Empirical Coverage: **100.0%**
- **Forecast Trajectory Chart:** Plotly line chart displaying historical series, forward point forecast, and shaded 95% state-space prediction interval polygon.
- **One-at-a-Time (OAT) Variance Decomposition:** Horizontal stacked bar showing the relative share of Forecast Error ($15.0\%$), Activity Measurement Uncertainty ($8.9\%$), and Emission Factor Uncertainty ($76.1\%$).
- **2026 Forecast Schedule Table:** Point forecasts, lower bounds, upper bounds, and uncertainty spreads for each month of 2026.

### 4.4 💡 Decarbonization Scenarios
- **Standalone Abatement Bar Chart:** Visualizes marginal carbon avoided ($\text{MTCO}_2\text{e}$) across the 5 canonical interventions (`INT-001` through `INT-005`).
- **Comprehensive Financial & Abatement Table:**
  - Intervention ID and Name
  - Target Category
  - Capital Cost (₹ Lakhs)
  - Baseline vs. Scenario Emissions (MT)
  - Annual Avoided Carbon (MT)
  - Relative Percentage Reduction (%)
  - Marginal Abatement Cost (₹/kgCO₂e)
- **Marginal Abatement Cost (MAC) Insights Box:** Highlights that LED Lighting (`INT-001`, ₹3.65/kg) and AC Optimization (`INT-003`, ₹4.16/kg) provide the greatest capital efficiency.

### 4.5 🎯 Portfolio Optimization
- **Optimal Portfolio Callout Banner:** Prominently details the selected optimal portfolio (`P-10110`), active projects (`INT-001` LED + `INT-003` AC + `INT-004` Waste), capital cost (₹9.5 Lakhs), carbon avoided ($225.8\text{ MTCO}_2\text{e}$), and remaining surplus (₹15.5 Lakhs).
- **Interactive Efficient Frontier Scatter Plot:**
  - X-axis: Capital Expenditure (INR Lakhs ₹).
  - Y-axis: Annual Avoided Carbon ($\text{MTCO}_2\text{e}$).
  - Feasible portfolios rendered in Navy Blue; Infeasible portfolios in Muted Grey.
  - Budget Cap indicated via a dashed vertical line at ₹25 Lakhs.
  - Optimal Portfolio highlighted with a bold **Gold Star (★)** marker.
  - Hover tooltips expose exact intervention combinations and MAC values.
- **Combinatorial Powerset Explorer Table:** Allows toggling between Feasible Portfolios and the complete 32-portfolio solution space, sortable by carbon avoided.

## 6. Supported Interactions vs. Prohibited Actions

### Supported Safe Interactions:
- **Page Navigation:** Instantaneous routing via the sidebar radio selector.
- **Target Category Selection:** Dropdowns on the Forecasting page allowing users to view Total, Electricity, or Travel models without recalculating.
- **Interactive Chart Controls:** Zooming, panning, and unified hover tooltips on all Plotly figures.
- **Table Exploration:** Column sorting and filtering between feasible and unconstrained portfolios.

### Prohibited Real-Time Actions:
- **No Calculation Sliders:** Sliders for "Adjust Budget" or "Adjust Emission Factors" that trigger on-the-fly recalculations are strictly prohibited to maintain analytical provenance. The dashboard reflects the verified state of the last pipeline run.

## 7. Error Handling & Diagnostics

If the user launches the dashboard before running the Phase 16 pipeline or if artifact files are missing or malformed:
1. The app intercepts `DashboardDataError` and `FileNotFoundError`.
2. A clean executive alert is rendered:
   ```
   ⚠️ Pipeline Artifacts Not Found or Incomplete
   Please execute the integrated pipeline before launching the dashboard:
   python -m src.pipeline
   ```
3. A collapsible `🛠️ Technical Diagnostic Details` expander reveals the exact missing file, empty table, or schema column mismatch for developers.
4. `st.stop()` is safely called, preventing unhandled exceptions or broken widgets.
