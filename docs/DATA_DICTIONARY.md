# Data Dictionary & Schemas

## 6. Dataset Schema (Activity Data)

> [!NOTE]
> **SIMULATED DATA NOTICE:**
> All activity data in `data/raw/campus_activity.csv` is **synthetic and simulated** for BDS-36 academic modeling. It reflects realistic campus archetypes and institutional seasonal dynamics (cooling loads, semester breaks, fiscal cycles), but does not represent actual utility records of any institution. Externally sourced emission factors remain strictly separate.

### 6.1 Raw Campus Monthly Activity Schema (`data/raw/campus_activity.csv`)

| Column Name | Data Type | Unit | Description | Realistic Range | Example |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `date` | Date (ISO YYYY-MM-DD) | Month Start | Start date of the monthly billing / accounting period. | 2023-01-01 to 2025-12-01 | `2023-01-01` |
| `building` | String | Categorical | Campus facility / building archetype identifier. | Campus building names | `Science & Engineering Complex` |
| `electricity_kwh` | Float (2 decimals) | kWh | Total monthly electrical energy consumed by the building. | 8,000 - 55,000 kWh | `38016.99` |
| `travel_km` | Float (2 decimals) | km | Total estimated commuter distance traveled by occupants. | 2,000 - 50,000 km | `38138.86` |
| `waste_kg` | Float (2 decimals) | kg | Total solid waste generated by the facility. | 600 - 7,000 kg | `2676.22` |
| `procurement_inr` | Float (2 decimals) | INR (₹) | Monthly operational expenditure / procurement for the facility. | ₹100,000 - ₹1,500,000 | `701168.27` |
| `student_count` | Integer | Headcount | Number of active students utilizing or resident in the facility. | 200 - 1,600 | `1174` |
| `staff_count` | Integer | Headcount | Number of active faculty, administrative, and support staff. | 25 - 100 | `78` |

### 6.2 Normalized / Tidy Activity Event Schema (Pipeline Transformed)

When transformed for carbon accounting engines, the tabular activity data can also be represented in normalized long/tidy format:

| Column Name | Data Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `date` | Date (YYYY-MM-DD) | Date of the activity or start of the billing period. | `2024-01-01` |
| `category` | String | High-level category (Electricity, Travel, Waste, Procurement). | `Electricity` |
| `subcategory` | String | Specific activity type. | `Grid`, `Commute_Car`, `Landfill` |
| `quantity` | Float | The numerical amount of the activity. | `15000.5` |
| `unit` | String | Unit of measurement for the quantity. | `kWh`, `km`, `kg` |
| `is_simulated`| Boolean | Explicit flag denoting that the activity data is synthetic. | `True` |


## 7. Emission-Factor & Intervention Schemas

### Emission Factors
Emission factors must be clearly sourced from external documentation (e.g., EPA, DEFRA).

| Column Name | Data Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `category` | String | Corresponding activity category. | `Electricity` |
| `subcategory` | String | Corresponding activity subcategory. | `Grid` |
| `emission_factor`| Float | Conversion factor to CO2e. | `0.453` |
| `ef_unit` | String | Unit of the emission factor. | `kgCO2e/kWh` |
| `source` | String | Documented source of the factor. | `EPA eGRID 2023` |
| `year_published` | Integer | Year the factor was published. | `2023` |

### Decarbonization Interventions
Used by the scenario optimization engine to select portfolios.

| Column Name | Data Type | Description | Example |
| :--- | :--- | :--- | :--- |
| `intervention_id` | String | Unique identifier for the project. | `INT-001` |
| `description` | String | Human-readable description. | `Rooftop Solar Phase 1` |
| `category` | String | Affected emission category. | `Electricity` |
| `capital_cost` | Float | Initial cost to implement the project ($). | `250000` |
| `annual_co2_reduction`| Float | Estimated reduction in kgCO2e per year. | `75000` |
| `lifespan_years` | Integer | Expected lifespan of the intervention. | `20` |
